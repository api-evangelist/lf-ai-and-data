# LF AI and Data (lf-ai-and-data)
LF AI and Data Foundation advances open source artificial intelligence, machine learning, and data projects under the Linux Foundation. It fosters collaboration to create scalable, trustworthy, and interoperable AI and data solutions through projects like Acumos AI, Angel ML, and Horovod.
